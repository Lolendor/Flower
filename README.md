# Тише, цветочек слушает

[![Открыть сайт](./open-site.svg)](https://lolendor.github.io/Flower/)

Оригинальный сайт: **https://lolendor.github.io/Flower/**

Цветочек реагирует на шум: в тишине растёт, при громких звуках вянет.
Микрофон используется только для измерения громкости в браузере.

Этот репозиторий содержит только готовую сборку сайта. Исходники хранятся
отдельно и не публикуются здесь.
